# Obsidian Legion Overlay: installers

Download the latest `Obsidian-Legion-Overlay-Setup-<version>.exe` from **Releases**.

The overlay is for Obsidian Legion members and recruits. Setup asks you to sign in with Discord;
it only works with the Obsidian Legion or Recruit role on the Legion Discord.

Installed copies update themselves from this page. Windows may show "Windows protected your PC"
on first install: click More info, then Run anyway.
